# Capstone Project: Full Adversary Simulation

## Executive Summary
A controlled Week 4 red team environment was prepared and documented using Kali Linux. Security tooling was validated, cloud tooling inspected, and reporting structures created.

## Findings
- Metasploit framework operational
- AWS CLI installed and verified
- Terraform and PowerShell available
- Local services documented

## Recommendations
- Maintain isolated lab practice
- Use credential-safe cloud testing
- Continue structured reporting

## 200-word Summary
The capstone activity focused on building a professional red team documentation workflow using a controlled Kali Linux environment. Core tools including Metasploit, AWS CLI, Terraform, Docker, PowerShell, and Nmap were verified successfully. Cloud tooling inspection demonstrated a clean baseline without configured credentials, showing safe operational readiness for future authenticated labs. Framework inspection confirmed Metasploit availability and module readiness for structured testing workflows. Reporting was aligned to PTES-style documentation by organizing findings, summaries, and remediation guidance into clearly separated files. Network and system baselines were captured to strengthen evidence quality. Rather than executing live offensive operations, the project emphasized environment readiness, safe methodology, repeatable workflow creation, and professional evidence handling suitable for academic red team training.
