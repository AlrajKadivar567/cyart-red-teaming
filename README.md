Cybersecurity Tool Analysis

This project demonstrates practical use of multiple cybersecurity tools in Kali Linux for reconnaissance, vulnerability scanning, web testing, anonymization, and binary analysis.

Tools Used
Nmap
theHarvester
Recon-ng
OWASP ZAP
sqlmap
Metasploit Framework
Tor
Proxychains
radare2
GDB
Main Tasks
Network scanning
Passive reconnaissance
Web vulnerability scanning
SQL injection testing
Proxy routing test
HTTP enumeration
Binary analysis
Local Test Environment

OWASP Juice Shop deployed using Docker for local testing.

Purpose

To understand how multiple security tools combine in a practical penetration testing workflow.
